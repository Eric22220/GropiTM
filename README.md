# ShockGrid — confortul pe bicicletă în Timișoara

**Aplicația:** https://eric22220.github.io/ShockGrid/

ShockGrid măsoară cât de denivelate sunt străzile și pistele din Timișoara cu telefonul fixat pe ghidon, colorează segmentele de stradă după vibrația măsurată (RVI — Relative Vibration Index) și compară / recomandă rute mai netede. Confortul nu e siguranță.

Documentația completă (pași pe telefon, Windows, scripturi) e mai jos — în curs de completare.
