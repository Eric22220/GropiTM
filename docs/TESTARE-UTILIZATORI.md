# Testarea cu utilizatori

**Stare: testul cu utilizatori nu s-a făcut încă.** Nu există participanți sau feedback de raportat; nu se inventează.

Protocol (9.5), dacă e timp: 3–5 persoane încearcă pe telefon:
1. importă o tură (ZIP Sensor Logger);
2. explică ce văd pe hartă (culorile, liniile întrerupte, străzile fără culoare);
3. aleg A și B și interpretează comparația rutelor;
4. interpretează ecranul Compară.

Se notează: ce au înțeles, ce nu, citate scurte **cu acordul lor**, fără nume.
